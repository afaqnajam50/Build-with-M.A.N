Admin inbox / setup notes (site owner)
This is a front-end template, not a secure admin dashboard yet. Do not put an admin password or Supabase service-role key in this HTML file.

For real two-way conversations, connect Supabase Auth + Database + Row Level Security (RLS). The owner signs in privately to an admin page; visitors receive a conversation code or use secure sign-in to return to their thread. Both sides' messages must be stored in the database. Without email notifications, visitors need to revisit the site to check for replies.

To finish the live system, configure a Supabase project, create tables for conversations and messages, enable RLS policies, then connect this form and a separate authenticated admin inbox. A single static HTML file cannot securely protect admin access by itself.

Safe setup: use only the Supabase project URL and publishable/anon key in browser code. Never expose service_role keys, database passwords or private secrets.
